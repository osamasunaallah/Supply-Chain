01 · The problem

Purchasing lived in PDFs, emails and memory.

With many projects running at once, nobody could quickly answer "Has this been ordered? Has it arrived? Where's the invoice?" I built the tool to answer all three in seconds.

BEFORE Manual tracking

  • Purchase requests typed by hand from PDFs, line by line
  • No single view of what is ordered, partial or still waiting
  • Invoices filed in folders with no link back to the order
  • Status updates collected by phone and chat every morning

AFTER Supply Chain Control

  • One click imports new PRs and POs straight from their PDFs
  • Every line shows its status, balance, deadline and owner
  • Invoice numbers become clickable links to the right PDF
  • Daily status reports are built as PDFs and emailed automatically
02 · Workflow

From request to closed order, end to end.

Each stage feeds the next automatically. Data is entered once, then reused everywhere it's needed.

1

PR received

Engineers raise purchase requests as PDFs in a shared folder.

2

Auto-import

VBA reads each PDF, parses items, quantities and job numbers, and spots revisions.

3

Supply Chain Master

Lines are tracked by PR with ordered qty, balance, deadline and owner.

4

PO Tracker

Issued POs are imported and matched back to their PR lines.

5

Receive & invoice

Received quantities sync back, and invoices are linked and dated.

6

Close & report

Completed PRs move to the archive, and the dashboard and reports refresh.

04 · Under the hood

Automation that saves hours every week.

Buttons on each sheet run VBA macros I wrote. Each one replaces a repetitive manual task.

PDF import

Extracts text from PR and PO PDFs, parses headers and item tables, assigns lines to jobs and flags revised documents. modImport

Invoice linking

Finds the right invoice PDF in each supplier's folder, scores possible matches, and turns the invoice number into a link. modLinkLines

Receipt sync

Matches PO lines to PR lines by item codes, sizes and words, then pushes received quantities and prices back to the master. modPOSync

Emailed PDF reports

Builds paginated daily status, open PO and invoice pending reports, and opens them ready to send in Outlook. modPdfPages

Instant search

A search bar on each sheet filters by job, PR, PO, item or person, and understands short and full job number formats. modSearch

Auto-archive & backups

Moves fully received PRs to Closed PR, and saves a timestamped backup before every structural change. Module1

05 · Code

Clean, modular VBA.

The logic is split into focused modules: import, sync, linking, reporting, layout and search. Each one finds columns by header name, so the sheets can change without breaking anything.

' Simplified: find a column by its header, not a fixed letter
Function ColOf(ws As Worksheet, header As String) As Long
    Dim c As Range
    Set c = ws.Rows(HeaderRow(ws)).Find(header, _
            LookAt:=xlWhole, MatchCase:=False)
    If Not c Is Nothing Then ColOf = c.Column
End Function

' Status of a PR line from ordered vs. received qty
status = IIf(recv >= qty, "RECEIVED", _

         IIf(ordered > 0, "ORDERED", "NOT ORDERED")))
