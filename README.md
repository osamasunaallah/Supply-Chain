# Supply Chain Control System

![Supply Chain Control System](thumbnail.png)

An Excel + VBA procurement control system that tracks purchasing from request to invoice.

**Live case study:** https://osamasunaallah.github.io/ET-Supply-Chain/

## What it does
- Imports purchase requests and purchase orders directly from PDF
- Tracks every line's ordered qty, balance, deadline, owner and status
- Syncs received quantities from the PO Tracker back to the master list
- Links each line to its invoice PDF automatically
- Builds daily status, open-PO and invoice-pending PDF reports for email
- Live dashboard with 6 charts and instant search

## Built with
Excel · VBA (~6,000 lines, 16 modules) · Dynamic arrays
